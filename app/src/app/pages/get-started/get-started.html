Get your first device online

One board, one sensor and a message on your phone. It takes about ten minutes.

You'll need

  • An ESP32, or an Arduino with Wi‑Fi
  • A sensora DS18B20 thermometer works well
  • A USB cable
  • Arduino IDE or PlatformIO

Create an account

Sign up with your email. Your workspace is ready as soon as you confirm it.

2

Copy a policy PIN

In the console, open Policies and create one called greenhouse. Choose Copy PIN. Every board in the policy joins with this PIN.

K7PX…HT4R Copy

Keep it private. If it leaks, choose Rotate PIN and the old one stops working.

3

Install the library

Arduino IDEPlatformIORaspberry Pi

Open Library Manager, search for WBSKT and install it.

4

Upload the sketch

Paste this in, add your PIN and Wi‑Fi details, and upload it to your board.

greenhouse.ino Copy
#include <Wbskt.h>

Wbskt wbskt("greenhouse-sensor", "your-policy-pin");

void setup() {
  wbskt.begin("home-wifi", "wifi-password");
}

void loop() {
  float temp = readTemperature();
  wbskt.send("reading", "temp", temp);
  delay(60000);
}
5

Check it's online

Open Clients in the console. greenhouse-sensor shows up within a few seconds. If the policy asks for approval, choose Approve.

6

Set your first rule

Open Workflows, create a new one and pick each part from the lists.

When greenhouse-sensor reads below 2 °C send a Telegram message

You're all set

You'll get a message the next time it gets cold.
