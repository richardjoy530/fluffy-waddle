Integrations

An integration holds the token, password or address a workflow needs to reach another service. Set it up once in a workspace, test it, and pick it from any node.

What you can connect

TTelegram

A bot token. WBSKT lists the chats your bot is in so you can pick one.

Used by the Telegram node
DDiscord

A channel webhook URL. Send plain text or rich embeds.

Used by the Discord node
@Email (SMTP)

Your mail server, port, sign-in and from address. Works with any SMTP provider.

Used by the Email node
nntfy

A topic on ntfy.sh or your own server, with an access token if it's protected.

Used by the ntfy node
HHTTP auth

A bearer token, basic sign-in or a header for a URL that needs one.

Used by the Call a URL node
HAHome Assistant

A ready-made HTTP auth: your instance's address and a long-lived token.

Used by the Call a URL node

Set one up

  1. In the console, open Integrations from the left rail and choose Add integration.
  2. Pick the service and give it a name you'll recognise in a node, like Family chat.
  3. Paste the token or sign-in. Secrets are encrypted at rest and never shown again, only replaced.
  4. Press Test. WBSKT sends a test message or makes a test call and tells you what came back.
  5. Pick the integration in any Email, Telegram, Discord, ntfy or Call a URL node.
Who can do thisViewing integrations needs integrations.read. Adding, changing or deleting one needs integrations.manage.

Telegram, step by step

Most people start here: a bot that messages you when something happens.

  1. In Telegram, talk to @BotFather, send /newbot and copy the token it gives you.
  2. Add your bot to a chat or group, and send it any message so it can see the chat.
  3. Add a Telegram integration in WBSKT with the token and press Test.
  4. In a Telegram node, pick the integration and choose the chat from the list.

Deleting an integration

An integration that a published workflow uses can't be deleted. The console lists the workflows that use it so you can change them first.
