Readings and commands

Your board sends readings to WBSKT, and WBSKT can send commands back. Both are short messages with a type and some data.

Send a reading

Pick a type that describes the message, like reading or alert, and send the values with it. WBSKT adds the time.

Copy
float temp = readTemperature();
wbskt.send("reading", "temp", temp);
var temp = ReadTemperature();
await wbskt.SendAsync("reading", new { temp });
# Coming soon: the Python library is not out yet.
temp = read_temperature()
wbskt.send("reading", {"temp": temp})

Every reading is kept for a year. You can chart it in the console or download it as a CSV file.

Receive a command

Workflows and the console can send your board a command, like switching a heater on. Tell the library what to do when one arrives.

Copy
void setup() {
  wbskt.begin("home-wifi", "wifi-password");
  wbskt.onCommand("heater", switchHeater);
}

void switchHeater(JsonObject data) {
  digitalWrite(HEATER_PIN, data["on"] ? HIGH : LOW);
}
wbskt.OnMessageReceived += (type, payload, commandId) =>
{
    if (type == "heater")
        heater.Switch(payload);
};
# Coming soon: the Python library is not out yet.
@wbskt.on_command("heater")
def switch_heater(data):
    relay.value = data["on"]

The library confirms delivery for you, so the console and your workflow runs show whether the command arrived.

Report what the board is doing

State is what your board is doing right now, like whether the heater is on. Report it when it changes and the console shows the latest value.

Copy
wbskt.reportState("heater", "on");
await wbskt.ReportStateAsync(new Dictionary<string, object?>
{
    ["heater"] = "on"
});
# Coming soon: the Python library is not out yet.
wbskt.report_state({"heater": "on"})

Good to know

  • A few types are reserved for WBSKT itself: capabilities, state.report and anything starting with sys.
  • Keep passwords and keys out of messages. Messages show up in your audit log.
  • Send readings when they change or every minute or so. Your board saves power and your charts stay readable.
