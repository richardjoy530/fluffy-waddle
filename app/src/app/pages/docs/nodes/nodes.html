Node reference

A workflow is a chain of nodes, which the console calls steps. Every run starts at a trigger, and the steps after it change the flow, wait, keep a value, do something or stop. Here are all 24, in the same groups and colours as the console's palette. Open one for its settings, what it adds to the run and an example.

Ports

A port is where a run leaves a node. Most nodes have one output, default, drawn as a single dot on the card's edge. Nodes with more than one outcome list them, and a run that reaches a port with nothing connected ends there as done. The canvas shows some ports by a friendlier name, given first below; the workflow definition and the API use the id.
