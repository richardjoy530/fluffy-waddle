Node reference

A workflow is a chain of nodes. Every run starts at a trigger, moves through control nodes and does things with actions. Here are all 24, with the ports each one leaves by and what it costs. Open one for its settings, what it adds to the run and an example.

Trigger: starts a run Control: changes the flow Wait: parks the run Action: does something Stop: ends the run

Ports

A port is where a run leaves a node. Most nodes have one output, default. Nodes that branch have one port per outcome, and a run that reaches a port with nothing connected ends there as done.

PortLeaves when
true / falseThe If node's conditions held, or didn't.
body / done / emptyOnce per item; after the last item; when the list had none.
timeoutA wait ran out before the callback, signal or acknowledgement arrived.
acked / failedThe client confirmed the command, or refused it (for example because it had expired).
errorThe URL answered with an error after its retries.
