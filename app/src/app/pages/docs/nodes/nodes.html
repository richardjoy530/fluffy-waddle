Node reference

A workflow is a chain of nodes. Every run starts at a trigger, moves through control nodes and does things with actions. These are all 24, with the ports each one leaves by and what it costs.

Trigger: starts a run Control: changes the flow Wait: parks the run Action: does something Stop: ends the run
CreditsStarting a run costs 1 credit, and each node it passes through costs more from your monthly allowance. Triggers are free, bookkeeping costs 0.1, a message to a client 1, Telegram, Discord, ntfy or a URL 5, and an email 10. See Plans and billing.

Ports

A port is where a run leaves a node. Most nodes have one output, default. Nodes that branch have one port per outcome, and a run that reaches a port with nothing connected ends there as done.
