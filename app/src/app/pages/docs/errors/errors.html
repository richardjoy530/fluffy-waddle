Error codes

Every error WBSKT returns carries a code to branch on and a traceId to quote when you ask for help. Codes never change meaning; new ones are only added.

404 application/problem+json 
{
  "status": 404,
  "title": "Not Found",
  "detail": "No such client.",
  "code": "CLIENT_NOT_FOUND",
  "traceId": "00-4bf92f3577b34da6a3ce929d0e0e4736-00"
}

A 400 from validation also carries errors, each field with its messages. A 429 or 503 carries a Retry-After header: wait that many seconds, then try again. The WebSocket has its own close codes.

Plans and limits

Reaching a plan's limit slows or pauses things. It never charges you. Running out of clients shows up as POLICY_LIMIT_REACHED when a board registers. The codes for running out of credits or messages arrive with billing; see what happens at a limit.
