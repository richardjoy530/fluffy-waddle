How credits are counted

Starting a run costs 1 credit, test runs and runs started by Run workflow included. Then the run spends credits for each node it passes through, as listed in the node reference. Waiting is free, and so is the trigger.

NodeCreditsWhy
Starting a run1Every run writes its own record and history.
Triggers0Covered by the start charge.
If, loops, fork, join, variable, delay, waits, end, fail0.1Bookkeeping inside WBSKT.
Console notification0.5A message to open consoles.
Send to client, Run workflow1Crosses to a board or another run.
Telegram, Discord, ntfy, Call a URL5Leaves WBSKT over someone else's network.
Email10Each email has a real cost to send.
ExampleA rule that checks soil moisture, switches a pump and sends you a Telegram message costs 1 + 0.1 + 1 + 5 = 7.1 credits a run. Free's 2,000 credits cover about 280 runs a month.

What happens at a limit

Reaching a limit slows or pauses things. It never charges you. You get a warning in the console at 80%.

LimitWhat happensWhat keeps working
ClientsA new board is refused at enrolment, with a code it can log.Boards already connected.
MessagesMessages are slowed until the 1st.Connections, commands, the console.
CreditsRuns pause where they are and new runs wait until a top-up or the 1st.Boards keep connecting and sending.
Workspaces, membersYou can't add another.Everything that exists.
