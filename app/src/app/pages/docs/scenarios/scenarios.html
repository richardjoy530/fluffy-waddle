What happens when…

Every scenario the docs answer, in one list. Each one links to the page that explains it, where the answer sits with the rules behind it.

Clients

Policies

  • A client starts with a PIN that doesn't exist
  • A client starts while the policy is disabled
  • The policy is full
  • The account is at its plan's client limit
  • I rotate the PIN while boards are being set up
  • I lower the limit below the clients already approved

Client lifecycle

  • Two boards use the same ID and secret
  • I revoke a client that is connected
  • A client is deleted, then starts again with its old credentials
  • A client's clock is wrong
  • A client was offline and sends a backlog
  • The account is frozen by WBSKT support

Commands

  • I send a command to an offline board
  • The board comes back after the command expired
  • The board drops in the middle of receiving it
  • A workflow sends to a board that is offline
  • I send to a client in another workspace
  • I ping an offline board

Capabilities, state and readings

  • A sensor fails and returns NaN
  • A board reconnects and sends an hour of buffered reports
  • I move to a plan that keeps readings for less time
  • A client's firmware adds a command

Workflows

Drafts, publishing and versions

  • I publish while runs of the old version are going
  • I publish a version whose trigger was removed while events were queued for it
  • A version publishes but can't be made live
  • Two people edit the same workflow through the API
  • Someone publishes while my draft is open
  • A workflow uses a client that was deleted
  • The workspace has 100 workflows

Runs

  • WBSKT restarts in the middle of a run
  • A run is left with nothing it can do
  • A path is waiting and its wait is lost
  • I cancel a run that already finished
  • Too many runs are going at once
  • I start a test run while one is going

Triggers in depth

  • The same message is delivered twice
  • Two workflows listen for the same thing
  • I turn a workflow off while events are queued
  • A board goes offline for 30 seconds with a 60-second offline trigger
  • The account is out of credits

Variables and placeholders

  • A placeholder names a value the run doesn't have
  • Two runs increment the same counter at once
  • A shared variable is set while a run is using it
  • I publish a new version
  • A path's data grows past 256 KB
  • A condition compares text with a number

Retries and failures

  • A URL answers 503 three times
  • A URL answers 404
  • WBSKT restarts while a step waits to try again
  • One of three split paths fails and the join waits for all
  • A step jumps back to an earlier step on failure
  • A run is left with nothing it can do
  • The parent of a Run workflow step fails

How the engine runs workflows

  • The engine restarts while a URL call is in flight
  • The engine restarts during a 2-hour delay
  • A client answers just as its wait times out
  • A step crashes in a way WBSKT didn't expect

Account

Audit log

  • A board keeps trying to join a full policy
  • A workflow sends a command to a client
  • Someone signs in with the wrong password
  • A member is removed from the workspace
  • I need something from four months ago

Usage and credit caps

  • One workspace reaches its cap while another has plenty
  • I set a cap below what the workspace has already spent
  • A run is going when its workspace reaches the cap
  • The month's credits run out at 23:50 on the 31st
  • A Free account uses its messages

Limits

  • I need more than a platform limit allows
  • A board floods the gateway with readings
  • The account hits its run limit
