Troubleshooting

The usual suspects, in the order we'd check them.

My board never shows up in Clients

Check the Wi‑Fi name and password first, then the PIN. A PIN that was rotated stops working straight away. Also make sure the policy isn't disabled.

It says Pending

The policy asks for approval. Open Clients, find the board and choose Approve.

It keeps going offline

Usually power or Wi‑Fi signal. The library reconnects by itself, and readings taken while it was offline arrive late but in order.

My rule didn't run

Make sure the workflow is published, not just saved. Then open its Runs tab: each run shows where it stopped and why.

No message on my phone

Open Integrations, pick the account the workflow uses and choose Send test. A wrong bot token is the most common cause.

Still stuck?

Ask on GitHub with what you tried and what you see. Someone will help you out.
